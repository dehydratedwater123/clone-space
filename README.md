# Clone Space
Creates an Android work profile and installs copies of your apps into it, so each copy has its own login.

## Get the APK (no Android Studio)
1. Create a GitHub repo, upload this folder's contents (keep the .github folder).
2. Actions tab -> "Build APK" -> run -> download the CloneSpace-apk artifact.
3. Install app-debug.apk on your phone (allow "install unknown apps").

## Or with Android Studio
Open the folder, then Build > Build APK(s).

## Use it
1. Open Clone Space, tap "Create clone space" and accept the prompts.
2. Reopen Clone Space on the personal side, tap an app to clone it.
3. Find the badged copy in your app drawer and log in with the second account.
